# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code.

## How to create a changeset

1. Run `pnpm changeset` in the root of the repository
2. Follow the prompts to select the packages that have changed
3. Write a summary of the changes
4. Commit the generated changeset file

## How to release

When changesets are merged to main, the CI will automatically:
1. Create a "Version Packages" PR with updated versions
2. When that PR is merged, publish the packages to npm

For more information, see [the Changesets documentation](https://github.com/changesets/changesets).
