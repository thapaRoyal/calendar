# CLI

The `@thaparoyal/calendar-cli` package provides a command-line interface for converting dates between AD (Gregorian) and BS (Bikram Sambat) calendars.

## Installation

```bash
npm install -g @thaparoyal/calendar-cli
```

Or use directly with npx:

```bash
npx @thaparoyal/calendar-cli
```

## Usage

### Convert AD to BS

```bash
ncal ad-to-bs 2024-01-15
# Output: 2080-10-01
```

### Convert BS to AD

```bash
ncal bs-to-ad 2080-10-01
# Output: 2024-01-15
```

### Get Today's Date

```bash
ncal today
# Output: Today's date in both AD and BS
```

### Interactive Mode

```bash
ncal
# Opens interactive mode with prompts
```

## Date Formats

The CLI accepts dates in the following formats:

- `YYYY-MM-DD` (e.g., 2024-01-15)
- `YYYY/MM/DD` (e.g., 2024/01/15)
- `DD-MM-YYYY` (e.g., 15-01-2024)
