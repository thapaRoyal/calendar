# Installation

There are two ways to install @thaparoyal/calendar:

1. **Using the CLI** (Recommended) - shadcn/ui style, copies components to your project
2. **Manual Installation** - Traditional npm package installation

## Using the CLI (Recommended)

The CLI provides a shadcn/ui-style experience where components are copied to your project, giving you full ownership and customization ability.

```bash
# Initialize configuration
npx @thaparoyal/calendar-cli init

# Add components
npx @thaparoyal/calendar-cli add calendar
npx @thaparoyal/calendar-cli add date-picker
```

See the [CLI documentation](/getting-started/cli/) for more details.

## Manual Installation

### React

```bash
npm install @thaparoyal/calendar-core @thaparoyal/calendar-react
```

```tsx
import { Calendar } from '@thaparoyal/calendar-react';
import '@thaparoyal/calendar-react/styles.css';
```

### Vue

```bash
npm install @thaparoyal/calendar-core @thaparoyal/calendar-vue
```

```vue
<script setup>
import { useCalendar } from '@thaparoyal/calendar-vue';
</script>
```

### Svelte

```bash
npm install @thaparoyal/calendar-core @thaparoyal/calendar-svelte
```

```svelte
<script>
import { createCalendar } from '@thaparoyal/calendar-svelte';
</script>
```

### Core Only

If you only need date conversion utilities:

```bash
npm install @thaparoyal/calendar-core
```

```typescript
import { adToBs, bsToAd, formatDate } from '@thaparoyal/calendar-core';
```

## Peer Dependencies

### React
- `react >= 18.0.0`
- `react-dom >= 18.0.0`

### Vue
- `vue >= 3.3.0`

### Svelte
- `svelte >= 4.0.0`

## TypeScript

All packages include TypeScript type definitions. No additional `@types` packages are needed.

## CDN Usage

For quick prototyping or non-bundled environments:

```html
<!-- UMD -->
<script src="https://unpkg.com/@thaparoyal/calendar-react"></script>

<!-- ESM -->
<script type="module">
  import { Calendar } from 'https://esm.sh/@thaparoyal/calendar-react';
</script>
```
