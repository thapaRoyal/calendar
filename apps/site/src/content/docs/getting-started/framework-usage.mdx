# Framework Usage

Use the site app for examples and demos:

- Home: `/`
- React playground: `/playground/react/`
- Angular snippets are included in the same playground code tabs.

## React (Prebuilt Components)

React currently has the most complete UI surface, including:

- `Calendar`
- `DatePicker`
- `RangeCalendar`
- `MultiCalendar`
- Month/year pickers and dropdowns

```tsx
import { Calendar, RangeCalendar, MultiCalendar } from '@thaparoyal/calendar-react';
import '@thaparoyal/calendar-core/themes/themes.css';
```

Use the React playground to see these components in action: `/playground/react/`.

## Vue (Composable-first)

Vue currently exposes a composable (`useCalendar`) for building your own UI while reusing the core calendar logic:

```ts
import { useCalendar } from '@thaparoyal/calendar-vue';

const calendar = useCalendar({ config: { calendarType: 'BS', locale: 'en' } });
```

The playground includes Vue snippets for each feature in the code tabs: `/playground/react/`.

## Svelte (Store-first)

Svelte currently exposes a store factory (`createCalendar`) for building your own UI while reusing the core logic:

```ts
import { createCalendar } from '@thaparoyal/calendar-svelte';

const calendar = createCalendar({ config: { calendarType: 'BS', locale: 'en' } });
```

The playground includes Svelte snippets for each feature in the code tabs: `/playground/react/`.

## Angular (Service-first)

Angular exposes injectable services built on top of the same core state machines:

```ts
import { CalendarService } from '@thaparoyal/calendar-angular';

@Component({ providers: [CalendarService] })
export class MyCalendarComponent implements OnInit {
  constructor(public cal: CalendarService) {}

  ngOnInit() {
    this.cal.initialize({ config: { calendarType: 'BS', locale: 'en' } });
  }
}
```

Use the Angular documentation for service-specific patterns:

- `/angular/quick-start/`
- `/angular/calendar-service/`
- `/angular/selection-service/`
- `/angular/date-picker-service/`
- `/angular/multi-calendar-service/`

## Core Utilities (All Frameworks)

Use `@thaparoyal/calendar-core` for:

- AD to BS and BS to AD date conversion
- formatting/localization
- calendar state logic and utilities

```ts
import { adToBs, bsToAd } from '@thaparoyal/calendar-core';
```
